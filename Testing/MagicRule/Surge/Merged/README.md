# MagicRule 合并测试版

本目录为唯一保留的 MagicRule 测试版本。原分类文件保留并补充域名；Rules/ 保存56个规则集。

Merged-Rule-Section.conf 按用户提供的注释、顺序和策略生成，替换 Mac 主配置的 [Rule] 段，保留其他所有配置段。不是完整配置，不能作为独立主配置导入。原手动规则、广告及系统更新拦截保留；社交新增 Social-Supplement；Rex维持DIRECT。

旧V2与其他草稿已按用户要求删除，旧配置中的125条V2引用需要立即用本文件替换，避免规则更新404。手机继续通过Mac主配置分离同步，不重复编辑。

该合并版保留55个原文件内容、增加12990条目标文件累计规则，存在跨文件覆盖顺序差异，尚需导入后实测，不代表全部域名连通性或解锁验证通过。summary.json为文件增量；additions-assignment.csv.gz为追加归属依据；report.json为构建状态。
